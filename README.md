**Веб-сайт + Android-приложение для получения рабочих прокси-серверов, оптимизированных для Telegram.**

Прокси обновляются **автоматически каждый день** из единого файла в репозитории.

---

## 🎯 О проекте

**Proxy Giver** — это экосистема из веб-сайта и Android-приложения, которая предоставляет актуальные, проверенные прокси для обхода блокировок Telegram.

### Как это работает?

### Для чего это нужно?
- Обход блокировок Telegram в странах с ограничениями.
- Быстрая смена прокси прямо из браузера или приложения.
- Бесплатный и простой доступ к рабочим прокси.
- **Автоматическое обновление** — не нужно искать прокси вручную.

## ✨ Возможности

### Общие:
- ✅ **Актуальные прокси** — автоматический парсинг каждый день в 00:00 UTC.
- 📋 **Копирование одним кликом** — кнопка "Копировать прокси".
- 🔄 **Ротация прокси** — если один не работает, можно получить другой.
- 📦 **Единый источник** — и сайт, и приложение читают один файл.

### Веб-сайт:
- 🌐 Работает на любом устройстве (ПК, iOS, macOS, Linux).
- ⚡ Минималистичный дизайн для быстрой загрузки.
- 🔗 Доступен через браузер без установки.

### Android-приложение (5+):
- 📱 Поддержка Android 5.0 и выше (API 21+).
- 🚀 Легковесное (менее 5 МБ).
- 🔄 Автоматическая проверка обновлений прокси при запуске.
- 📋 Кнопка "Скопировать" + возможность сразу открыть настройки Telegram.
- 🌙 Тёмная тема.

## 🚀 Быстрый старт

### Для пользователей (как получить прокси)

#### Вариант 1: Веб-сайт (ПК, iOS, любой браузер)
1. Перейдите на сайт: **[https://mtproto-proxy.vercel.app/](https://mtproto-proxy.vercel.app/)**
2. Нажмите кнопку **"обновить прокси"**.
3. Нажмите **"Копировать"** или **"открыть"**.
4. Вставьте в настройки Telegram:
   - **Настройки** → **Продвинутые** → **Тип соединения** → **SOCKS5**
   - Введите хост:порт (и логин/пароль, если есть).

#### Вариант 2: Android-приложение
1. Скачайте APK из [Releases](https://github.com/mreliseyyt/proxy-giver/releases).
2. Установите (разрешите установку из неизвестных источников).
3. Откройте приложение — прокси подгрузится автоматически.
4. Нажмите **"Скопировать"** или **"Открыть Telegram"** (если приложение установлено).
